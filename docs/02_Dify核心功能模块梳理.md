# Dify 核心功能模块梳理

> 对象：Dify（https://dify.ai）
> 整理日期：2026-07-12
> 说明：本仓库为 Dify 的 fork 但当前尚无源码，内容基于官方产品与文档梳理。

## 〇、Dify 到底是什么？（先读这一节）

**一句话**：Dify 是一个「**搭建 AI 应用的低代码平台**」——让你不用从零写代码，就能把大模型（如 GPT、Claude、通义）+ 你自己的数据 + 各种工具，组装成一个能上线、能被别人使用的 AI 应用。

**它解决什么问题？**
自己用大模型做一个能用的产品，往往要处理一堆脏活：调各家模型的 API、把公司文档做成能被 AI 检索的知识库、写多轮对话逻辑、让 AI 会调用工具、上线后还要看日志和成本……Dify 把这些**都做成了可视化的现成模块**，你在网页上拖拽、配置就行，省掉大量工程搭建。

**能拿它做出什么？（几个具体例子）**
- 一个**企业内部客服机器人**：上传产品手册当知识库，它就能基于手册回答员工/客户提问。
- 一个**智能体（Agent）**：给它接上搜索、计算器、数据库工具，它能自己拆解任务、多步调用工具完成，比如「查一下上季度销售额并生成图表」。
- 一个**自动化工作流**：比如「收到一封邮件 → 自动分类 → 提取关键信息 → 写好回复草稿」，全程无人值守。
- 一个**文本处理 API**：把「批量翻译/摘要/审核」做成接口，供你自己的系统调用。

**谁用它？**
- **开发者**：快速搭原型、把 AI 能力以 API 形式接进自家产品，省去底层搭建。
- **产品/运营等非重度编程人员**：靠可视化编排也能做出可用的 AI 应用。

**一句话记住它的定位**：
> **模型能力**（接哪个大模型）+ **你的数据**（知识库/RAG）+ **工具**（让 AI 能干活）→ 通过 Dify 的**可视化编排**，快速变成一个**能发布、能集成**的 AI 应用。

下面各节，是对上面这套能力「内部由哪些模块组成」的详细拆解。

## 一、应用类型（Application Types）

> 对应「你想做哪一类 AI 应用」——这是使用 Dify 的第一个选择。

平台围绕不同场景提供五种可视化编排的应用类型。

| 模块 | 说明 |
|------|------|
| **聊天助手 Chatbot** | 最基础的对话式应用，基于提示词 + 知识库快速搭建单一角色的问答/客服机器人。 |
| **智能体 Agent** | 能自主推理的对话应用，通过 ReAct / Function Calling 自行选择并调用工具、多步完成复杂任务。 |
| **文本生成 Text Generation** | 面向单轮生成任务（翻译、摘要、文案、分类等），输入变量即产出结果，适合批量与 API 调用。 |
| **对话流 Chatflow** | 面向多轮对话的工作流，带会话记忆，可在对话中编排分支、检索、工具调用等复杂逻辑。 |
| **工作流 Workflow** | 面向自动化任务的编排（单次或批处理），把 LLM 与各类节点串成可视化的有向流程。 |

---

## 二、提示词编排（Prompt Engineering / Prompt IDE）

| 模块 | 说明 |
|------|------|
| **Prompt IDE** | 可视化编写、调试提示词的工作台，支持变量插入、上下文/知识库挂载与实时预览。 |
| **变量与表单 Variables** | 把提示词中的可变部分抽象成输入表单，实现应用的参数化与复用。 |
| **多模型调试 Model Comparison** | 同一提示词并排对比不同模型/参数的输出，辅助选型与调优。 |

---

## 三、知识库与 RAG（Knowledge / Retrieval-Augmented Generation）

| 模块 | 说明 |
|------|------|
| **知识库 Knowledge Base** | 上传/接入文档并向量化，作为应用的私有知识来源，实现基于自有数据的问答。 |
| **数据接入与 ETL** | 支持本地文件、Notion、网页抓取等多种数据源导入，并做文本抽取与清洗。 |
| **分段与清洗 Chunking** | 将文档切分为可检索片段，支持自动/自定义分段规则与预处理。 |
| **索引模式 Indexing** | 提供「高质量」（向量嵌入）与「经济」（关键词）两种索引方式，平衡效果与成本。 |
| **检索策略 Retrieval** | 支持向量检索、全文检索、混合检索，并可接入 Rerank 重排序提升召回质量。 |
| **元数据 Metadata** | 为文档/片段附加元数据，实现过滤检索与更精细的召回控制。 |

## 四、工作流节点（Workflow Nodes）

工作流/对话流由可拖拽的节点组成，核心节点包括：

| 节点 | 说明 |
|------|------|
| **LLM** | 调用大模型完成生成、推理等核心任务。 |
| **知识检索 Knowledge Retrieval** | 从知识库召回相关内容注入上下文。 |
| **问题分类器 Question Classifier** | 用 LLM 对输入意图分类，驱动后续分支走向。 |
| **条件分支 IF/ELSE** | 按条件对流程分流。 |
| **代码执行 Code** | 运行 Python/Node.js 代码做数据处理与自定义逻辑。 |
| **模板转换 Template** | 用 Jinja2 模板格式化/拼装文本。 |
| **HTTP 请求** | 调用外部 API，接入第三方系统。 |
| **工具 Tool** | 调用内置或自定义工具（搜索、绘图、代码等）。 |
| **参数提取 Parameter Extractor** | 从自然语言中抽取结构化参数供下游节点使用。 |
| **迭代 / 循环 Iteration/Loop** | 对数组或条件做批量/重复处理。 |
| **变量聚合 Variable Aggregator** | 汇聚多分支变量，统一后续引用。 |
| **回复 / 结束 Answer/End** | 输出结果，结束或流式返回给用户。 |

## 五、工具与插件（Tools & Plugins）

| 模块 | 说明 |
|------|------|
| **内置工具 Built-in Tools** | 平台预置的搜索、绘图、代码、天气等工具，可直接被 Agent/工作流调用。 |
| **自定义工具 Custom Tools** | 通过 OpenAPI/Swagger 定义把任意 REST API 封装成工具。 |
| **插件市场 Marketplace** | 安装、发布插件的生态入口，扩展模型、工具与能力。 |
| **插件体系 Plugin System** | 支持模型插件、工具插件、Agent 策略、扩展（Extension）与打包（Bundle）等多种插件类型。 |

---

## 六、模型管理（Model Management）

| 模块 | 说明 |
|------|------|
| **模型供应商 Providers** | 统一接入 OpenAI、Anthropic、通义、本地/Ollama 等数十家模型供应商与自托管模型。 |
| **系统模型设置** | 为推理、Embedding、Rerank 等分别指定默认模型，供全局应用使用。 |
| **多模型类型** | 支持 LLM、文本嵌入 Embedding、重排序 Rerank、语音转文本、文本转语音、内容审核等多种模型能力。 |

---

## 七、可观测与运营（Observability & LLMOps）

| 模块 | 说明 |
|------|------|
| **日志与标注 Logs & Annotation** | 记录每次会话的完整输入输出，可对回答进行人工标注与「标注回复」以持续优化。 |
| **监控看板 Monitoring** | 统计调用量、费用、Token、用户活跃等运营指标。 |
| **链路追踪 Tracing** | 接入 LangSmith、Langfuse、Opik 等，追踪工作流内部每一步的执行细节。 |

---

## 八、发布与集成（Publishing & Integration）

| 模块 | 说明 |
|------|------|
| **Web 应用** | 一键发布成可分享的独立 Web 应用（含 WebApp 模板与访问控制）。 |
| **嵌入式组件 Embed** | 以浮窗/iframe 形式嵌入到任意网站作为在线助手。 |
| **后端服务 API** | 每个应用自动暴露 REST API，供自有产品以「后端即服务」方式集成。 |
| **difyctl CLI** | 命令行工具，在终端、脚本、CI 与 AI Agent 中运行 Dify 应用。 |

---

## 九、平台与部署（Platform & Deployment）

| 模块 | 说明 |
|------|------|
| **云服务 Dify Cloud** | 官方托管的 SaaS，开箱即用。 |
| **社区版 / 自托管** | 通过 Docker Compose 等方式私有化部署，数据自主可控。 |
| **企业能力** | 团队/工作空间、成员权限（RBAC）、SSO 等协作与治理能力。 |

---

### 一句话总览

Dify 把「**应用编排（五种应用类型 + 工作流）**、**知识（RAG 知识库）**、**能力（工具/插件/模型）**、**运营（可观测/LLMOps）** 与 **交付（Web/API/CLI 发布）**」整合为一个可视化的 LLM 应用开发平台，让开发者无需从零搭建即可快速构建、上线并持续优化 AI 应用。
